# Camera Calibration and Tracking Demo

This repository contains two main scripts:

1. **`camera_calibration.py`** - For calibrating a camera's perspective by creating a homography matrix.  
   - **Input:**
     - Camera image  
     - Floor plan image  
     *(Edit the code to provide the correct paths to your input files.)*  
   - **Output:**
     - Homography matrix and calibration data saved in the `./calibrated` directory.

2. **`tracking_demo.py`** - For tracking objects in video streams and projecting their positions onto a floor plan.\
   *(Currently using Ultralytics and openvino models for detection and reid)*
   - **Input:**
     - Floor plan image  
     - Camera video  
     - Calibration files (generated by `camera_calibration.py`).  
     *(Edit the code to provide the correct paths to your input files and calibration files.)*  
   - **Output:**
     - Annotated video frames  
     - Real-time projection of tracked objects onto the floor plan.

---

## Prerequisites

Before running the scripts, ensure you have the following:

- **Python Version:** Python 3.8 or later
- **Required Libraries:**
  - OpenCV
  - NumPy
  - Scikit-learn
  - Ultralytics
  - PyTorch
  - OpenVINO
  - Norfair
  - Supervision
- **Input Files:**
  - Floor plan image
  - Camera images or video files

You can install the required libraries with the following command:
```bash
pip install opencv-python numpy scikit-learn ultralytics torch torchvision openvino norfair supervision
```
